# ⚔️ 문명 전쟁 온라인 — 영구 월드

접속하면 모두가 함께 쓰는 **하나의 거대한 세계 지도**에 떨어지는 문명 전략 게임.
외부 패키지 없이 Node.js만으로 동작합니다.

## 폴더 구조
```
server.js
package.json
public/
  index.html   (화면·스타일)
  game.js      (게임 화면 동작)
  rules.js     (서버·화면 공용 규칙)
  icons.js     (SVG 아이콘)
```

## Render 배포
1. 위 파일을 GitHub 저장소에 올립니다 (`index.html`, `game.js`, `rules.js`, `icons.js`는 반드시 `public` 폴더 안).
2. Render → New → Web Service → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포된 주소로 접속하면 바로 세계에 입장합니다.

## 환경 변수 (선택, Render의 Environment 탭)

## 세계가 초기화되지 않게 하기 (중요)
Render 무료 서버는 15분간 접속이 없으면 잠들고, 잠들거나 다시 배포하면 디스크가 지워집니다.
그래서 세계를 **GitHub Gist**에 압축 저장하도록 만들었어요 (무료, 2분마다 + 서버가 꺼질 때 저장).

1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token
   - 권한(scope)은 **gist** 하나만 체크 → 생성된 토큰을 복사
2. https://gist.github.com 에서 아무 내용으로 **Secret gist** 하나 만들기 (파일명·내용 아무거나)
   - 주소 `https://gist.github.com/아이디/abcd1234...` 의 마지막 부분이 **GIST_ID**
3. Render 대시보드 → 서비스 → **Environment** 에 추가
   - `GITHUB_TOKEN` = 복사한 토큰
   - `GIST_ID` = 위의 ID
4. 저장하면 재배포되고, 로그에 `저장소 GitHub Gist`가 보이면 성공

이제 아무도 없으면 **시간만 멈추고**, 서버가 잠들었다 깨어나도·다시 배포해도 세계가 그대로 이어집니다.
(예전 버전 저장 파일도 자동으로 새 규칙에 맞춰 불러와요)
선택: `KEEP_AWAKE=1` 을 넣으면 서버가 스스로 깨어 있도록 접속합니다 (무료 사용 시간을 사용).

## v5 업데이트: 사령관 · 지배층 · 총독 · 넓은 바다
- **한 번 새 세계**: 맵이 96×64로 커지고 바다가 52%로 넓어져서, 예전 저장(v4 이하)이 있으면 **이번 한 번만** 새 세계가 만들어집니다. 예전 세계를 지키고 싶으면 환경 변수 `KEEP_OLD_MAP=1`.
- **사령관** (국정 › 사령관): 후보 3명 중 임명 (20턴마다 새 후보). 특성 2개, 승리로 레벨 1~5 성장. 지휘 시점 `지휘하지 않음 / 오프라인일 때만 / 항상`, 방침 `방어 / 균형 / 공격`. 전투 화면의 [사령관 위임]으로 그 전투만 맡길 수도 있습니다. 유지비 턴당 금 2+레벨.
- **지배층** (국정 › 지배층·총독): 귀족·성직자·상인·군부·관료·지식인·노동자. 정부와 정책이 영향력을 정하고, 충성도 60 이상이면 보너스, 30 미만이면 안정도 하락과 쿠데타(군부)·반역(귀족)·혁명(지식인·노동자) 위험. 특권 부여 / 견제 가능 (8턴 쿨다운).
- **총독**: 도시마다 행정관·재무관·학자·농정관·문화관·수비대장 중 하나. 자리 수 = 1 + 시대 2개마다 1 + 중앙집권 정부 1 + 전통 정책 3개 이상 1.
- **바다**: [항해술] 기술로 해안 2칸 얕은 바다, [항법]으로 먼바다 이동. 바다 위 유닛은 배로 표시되며 방어력 40%, 회복 불가, 바다에서 공격 불가(상륙 후 공격). 항구는 해안 도시에만.

## v6 업데이트: 대륙 2개 · 해전 · 공군 · 기술 가지
- **한 번 새 세계**: 맵이 120×76, 대륙 2개로 바뀌어 예전 저장(v5 이하)은 이번 한 번 새 세계로 시작합니다. 예전 세계를 지키려면 `KEEP_OLD_MAP=1`.
- **기술 가지**: 기술 화면이 선으로 이어진 가지 모양. 기술을 누르면 그 기술까지의 길이 보라색으로 표시되고, [여기까지 자동 연구]로 필요한 기술을 차례로 예약 연구.
- **기습 공격**: 선전포고 없이 다른 나라 유닛·도시를 공격 가능(두 번 눌러 확인). 즉시 전쟁이 시작되고 상대(−40)와 다른 나라들(−12)의 평판이 떨어집니다. 동맹·신규 보호 국가는 불가.
- **해군**: 돛단배(갈레선) → 조선술(삼단노선·조선소) → 지도 제작 → 항해술(캐러벨) → 해군 전술(프리깃) → 증기선(철갑함) → 근대 해군(구축함·전함) → 잠수함 기술 → 항공모함 운용 → 유도 미사일(미사일 순양함). 함선은 해안 도시에서 만들고 바다로만 이동, 바다 위 적을 전투로 공격하거나 사거리 함선은 해안까지 포격. 함선과 같은 칸의 육군은 함선이 지켜 줍니다.
- **공군**: 항공(전투기·폭격기·공항) → 제트 엔진(제트 전투기) → 스텔스(스텔스 폭격기) → 무인기(공격 드론). 도시·항공모함에 주둔하며 사거리 안 어디든 공습, 전투기는 사거리 안 적 공습을 자동 요격(공습 위력 절반). 항공모함은 3대 탑재, 침몰하면 탑재기도 잃습니다.

## 격변과 기술 발전
- 전쟁·혁명·쿠데타·반역·폭동·도시 함락은 **격변 지수**를 올려 과학을 최대 +90% 가속합니다.
- 오래 평화롭고 안정도가 높으면 사회가 안주해 과학이 최대 −70%까지 느려집니다. (국정 › 안정도에서 확인)
- 전쟁 피로가 크게 강해졌습니다: 전쟁마다 기본 감소 + 전쟁이 길어질수록 추가 감소 + 전사자 감소, 여러 전쟁을 동시에 하면 배로 증가, 전쟁 중엔 안정도가 매 턴 최대 9씩 떨어집니다.
- 현·근대 기술 21개 추가 (전신·철도·백신·전화·원자물리학·항생제·대중매체·항공·트랜지스터·원자력·반도체·자동화·유전공학·인터넷·이동통신·재생에너지·기계학습·빅데이터·자율주행·양자 컴퓨터·범용 인공지능 등)와 건물 3개 (원자력 발전소·반도체 공장·데이터센터).

## 다른 행성 개척
- 우주선을 발사한 뒤 새 기술 **행성 간 추진**을 얻으면, 발사대 도시에서 **식민선**을 만들어 달·화성에 식민지를 세울 수 있습니다.
- **테라포밍**: 금성·유로파·타이탄 + 식민지 최대 레벨 5 / **궤도 전쟁**: 궤도 함대로 전쟁 중인 나라의 식민지 점령 / **항성 간 항법**: 다른 별의 행성 케플러-442b.
- 식민지는 매 턴 금·과학·문화(생산은 수도로)와 행성 특산 자원을 보내고, 금·자원으로 레벨을 올릴 수 있습니다. 화면: 국정 › 행성 개척.

## 주요 시스템
- **자원**: 목재·석재·구리·말·철·석탄·초석. 일꾼이 광산/목장/벌목장/농장을 짓거나 직접 채집. 도시마다 1+인구/2곳의 시설이 가동
- **자원 사용**: 유닛·건물 생산, 일부 기술 연구 시작, 장비 제작에 필요
- **장비**: 도시 [제작] 탭에서 무기·갑옷·군마 제작 → 무기고 → 내 영토 안 유닛에 장착
- **외교**: 전쟁/평화, 평화 조약·불가침(깨면 배신), 국경 개방(없으면 남의 영토 통행 불가), 동맹(시야 공유·참전 요청), 태도·신뢰도
- **교역**: 거래 제안(금·턴당 금·턴당 자원·일시 자원 + 조약), 세계 시장 수입/수출 (수요·공급 가격)
- **부대**: 한 칸에 유닛 무제한, 체크한 유닛끼리 함께 이동·공격
- **전투 미니게임**: 적 칸 공격 시 3라운드 전술전 (돌격 > 사격 > 방진 > 돌격), 적 성향 힌트, 후퇴·자동 전투. 원거리 유닛은 반격 없는 포격

- **안정도**: 전쟁 피로·제국 규모·점령지·낡은 정부·굶주림 등으로 변동. 낮으면 폭동·혁명·쿠데타·분리 독립(반군 국가 탄생). 축제로 일시 회복, 다른 나라에 반군 지원 공작 가능
- **기업 7종**: 세계에 하나씩, 본사 설립 → 지사 개설(해외 진출 가능), 원료 소비·수익·도시 효과, 국유화, 본사 점령 시 기업 이전
- **우주**: 로켓 공학 → 발사대 → 정찰 위성(지도 공개)·추진체 3·거주 모듈·핵융합 엔진 → 우주선 발사(영구 보너스)
- **일꾼**: 자원·시설 칸에 최대 3명, 함께 지으면 빨리 완성, 상주 채굴로 추가 자원
- **전쟁 속도**: 유닛 체력 60, 피해 증가, 병력 생산 비용 절반, 인구 성장 2배

## 게임 규칙 요약
- 처음 접속하면 세계의 빈 땅에 개척자·전사·정찰병과 함께 시작
- 같은 기기로 다시 들어오면 자동으로 내 제국으로 복귀
- 일정 시간마다 자동으로 턴 진행 (접속자 전원이 [준비]를 누르면 더 빨리 진행)
- 신규 보호: 입장 후 일정 턴 동안 선전포고 불가 (내가 먼저 선전포고하면 해제)
- 늦게 들어온 사람은 세계 문명 절반 이상이 아는 기술과 보너스 금을 받고 시작
- 외교: 만난 문명에게만 선전포고/평화 제안 가능
- 멸망하면 다른 빈 땅에서 다시 시작 가능
- AI 문명이 멸망하면 시간이 지난 뒤 새 AI 문명이 등장
- 미니맵, 세계 순위, 세계 채팅
